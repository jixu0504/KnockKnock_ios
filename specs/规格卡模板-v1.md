# 规格卡模板（Spec Card Template）v1.0

> 工程纪律（计划书 v1.1 §三.2）：**每个模块先产出规格卡，reviewer 批准后才写实现。**
> 使用方式：复制本文件到 `ios-port/specs/<模块名>-spec.md`，逐节填写；reviewer 在 `评审结论` 签字（通过/退回+理由）后，实现代理方可开工。
> 黄金法则：Android 1.14.27 是行为 oracle；所有「行为」描述必须指向 Android 源码位置（file:line）。

## 输入 / 输出 / 边界

- 输入：类型、来源（UI/其他域服务/外部）、空值与非法值行为
- 输出：类型、去向（DB/网络/UI 流）、副作用（表写入、通知、文件）
- 边界：上限（消息数/记忆数/文件大小）、超时（首 token/总时长/取消语义）、并发（重入、双发）、错误（网络/超时/供应商拒绝/磁盘满/权限拒绝）逐项行为
