# 实现报告：界面去开发者化（0.3.0 测试版）

| 项 | 结果 |
|---|---|
| 目标 | 减少记忆/印象相关界面里的开发者元素，保持普通用户可读、界面整洁 |
| 验证 | `xcodebuild` 模拟器 BUILD SUCCEEDED；全量 **715 tests / 8 failed**（基线网络测试） |
| 截图 | `docs/assets/memory-clean.png`、`impressions-clean.png`、`settings-clean.png`、`ranking-clean.png` |

## 1. 记忆管理
- 「记忆体检」→「记忆维护」，默认**收起**；摘要只显示「一切正常 / 有 N 条记忆需要整理 / 整理遇到问题」；
- 原始计数（可用/缺失/漂移/过期/整合失败）与「检查记忆状态 / 修复记忆」收进展开区；
- 详情页去掉 `ID xxx`、`shared DB` 等内部信息；「锚点」→「来源」，「旧版六类锚点（memory_anchors）」→「补充来源」；
- 列表去掉「旧版长期印象 / 重要度 未标注」，改为「早期记录」，空重要度不展示。

## 2. 印象页
- 摘要去掉「旧版 memories 只读兜底，未与记忆管线 L3 重复」等内部说明，改为「含 N 条早期记录」；
- 行内去掉「旧版」徽章、置信度百分比、重要度数字；类型/来源 chip 去重（相同不重复展示）；
- 保留角色分组、层级筛选、分页、证据与拒绝/冻结/编辑入口。

## 3. 设置与排行榜
- 设置「数据与诊断」→「数据」，移除「调试日志」入口（仍可通过启动参数/文件访问）；
- 设置「App」显示产品名「敲敲」，不再显示内部工程名；
- 排行榜移除 Token 消费面板与「消费（估算）」维度，只保留消息数/互动天数。

## 4. 未动 / 保留
- 自检面板仍只在 `--selftest` / `--*-selftest` 启动参数下出现，普通启动不可见；
- 深链 `rhodes://settings/debugLogs` 等仅开发使用，无 UI 入口；
- 「离线」徽章、本机数据卡属于产品状态，不是调试信息；
- 未提交 git；Android 端 UI 未同步。

## 5. 后续
- 真机走查（按 `docs/记忆与印象-0.3.0-实机测试说明.md`）；
- 若产品希望完全隐藏「记忆维护」，可再加长按版本号才显示的开发者入口。
