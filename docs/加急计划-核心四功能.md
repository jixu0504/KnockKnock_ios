# RhodesLink iOS 加急版开发计划（2026-11-23）

> 目标：尽快交付一版**真机可用**的加急版本，聚焦四项核心能力。范围外的功能一律冻结，不占用加急窗口。
> 依据：主计划书 v1.1（P0/P1 优先级）+ 用户 2026-11-23 加急要求。

## 一、加急版验收范围（必须全部可用）

| # | 功能 | 验收标准（可自动判定 / 真机可验证） |
|---|---|---|
| 1 | **基础私聊可用** | 配置真实供应商 API Key 后：发消息 → 真实流式回复 → 落库 ✅ 历史分页 ✅ 停止生成 ✅ 失败重试 ✅ 图片消息 ✅；提示词含角色人设 + 记忆/知识库注入（T45） |
| 2 | **人设编辑完整** | 角色创建/编辑：姓名、头像（内置 147 选择 + 相册上传裁剪）、人设描述、标签、初始关系、提示词槽位覆盖；角色详情页可进入编辑并保存生效（新会话即用新人设） |
| 3 | **提示词编辑完整可用** | 设置→提示词：分类浏览、查看当前文本（默认/自定义标记）、编辑保存、恢复默认、启用/禁用、变量占位符说明；保存后下一轮聊天生效（T46） |
| 4 | **动态、日记完整可用** | 动态：列表/发布/点赞/评论/删除/刷新/空态/错误态；日记：列表/未读标记/阅读详情；数据落库、重启保留 |

**不在加急范围**：记忆管理页完善（已完成基础版）、知识库 UI、群聊深化、A7 后台自动化、语音/游戏、内容生成（AI 生成动态/日记可后续）、关系网编辑、身份/等级页。

## 四、质量门禁（加急版不降低）

1. `:shared:testDebugUnitTest` 全绿；`:app:testDebugUnitTest` 全绿
2. 每项功能有自检钩子（`--persona-selftest` / `--moments-selftest` / `--diary-selftest`）与 DB 核对
3. 真机安装后逐项验收清单（见 §一）
4. 崩溃为 0（加急版允许功能缺失，不允许阻断崩溃）
