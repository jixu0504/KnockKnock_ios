## 一、本版包含什么

1. **记忆正确性**：回复后维护接线（摘要/晋升/清理）、过期宽限清理、索引缺失/漂移修复、恢复备份后重建、诊断日志。
2. **检索**：BM25 词法索引 + 双通道召回、查询意图、校准准入与拒答、RRF 融合、同主题最多 2 条、父子去重、相反极性只注入较新一条、实体通道（私聊）。
3. **事实与冲突**：结构化事实键、事实表、关系表（supports/contradicts）、冲突标记 `suspected`、确认后关闭旧事实有效期；整合幂等/退避/dead-letter/日预算。
4. **印象**：`impressions` 一等表（层级/置信/证据数）、证据链（≤8 条、层级权重）、历史回填、页面按角色分组/层级筛选/分页、证据摘要跳会话、拒绝/冻结/撤销/编辑（写历史）。
5. **设置与体检**：记忆分区（总开关、跨角色回忆、体检入口、保留期 30/90/永久）、体检面板（索引状态、整合失败、重建按钮）。
6. **备份**：事实、关系、印象、证据纳入全类目备份 v2；恢复时 id 映射与证据外键回填。

## 三、已知限制 / 不要误判

- **不支持降级安装**：schema 已升到 33，装回 0.2.0 会因数据库版本高而无法启动；升级前建议先导出备份。
- **8 条基线网络测试失败**：`KtorDarwinStreamingTest` 需要本地 127.0.0.1 测试服务，非本版回归。
- **抽取合规率未测**：结构化字段依赖模型输出；不合规时只影响 L2/L3/印象形成，不影响已存记忆正确性。
- **实体通道仅私聊**，且查询需包含完整实体名；2 字短名可能误命中。
- **冲突确认/取代没有 UI**：目前只有仓储 API，冲突会标记 `suspected` 但不会自动关闭旧事实。
- **印象证据不参与备份内容过滤**，残缺包可能产生孤儿证据（需 `deleteOrphans`）。
- **Android**：兼容 DDL 已补，但本机无 Android SDK，未实编；当前产物只面向 iOS。
- **未提交 git**：所有改动仍在工作区，发版前需按主题分提交并打 tag。
- **App Store 提审前**还需补 `PrivacyInfo.xcprivacy` 与隐私政策文案。
