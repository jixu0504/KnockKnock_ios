## 维护约定

- 新增设置键必须同时给出「生产读取点」与至少一条测试；无消费者的键在下一个里程碑删除或标 `deprecated`。
- 本清单随每个里程碑更新；`T86` 完成后应只剩第 1、5、6 条的历史兼容项。
