## 五、风险（按影响排序）

1. **评测集只有检索层 v0**：词法与准入规则已有 tune/holdout 基线，但仍缺「模型抽取 → 记忆 → 召回」的端到端回放；语义类问题（年龄/乐器/安排）在本地哈希向量下必然失败，需第三方/端侧嵌入或实体通道。
2. **长期印象仍取决于模型是否按 v3 输出结构化字段**：晋升分组已从内容指纹改为事实键，但抽取合规率未测；不合规会回退旧指纹（安全但不可达）。需要 T68 端到端回放验证，再做 T77 整合 Worker。
3. **印象不是独立实体（M3）**：无证据链、无置信度、无纠错/冻结；本轮只做了展示降噪。
4. **存储**：向量仍以 JSON 文本存行内（T71 未做）；词法倒排单条最多 160 term，长期有体积压力（T79 需标定并补删除路径）。
5. **迁移编号偏离计划**：词法索引占用迁移 24，向量 BLOB 顺延；已在迁移文件与 handoff 记录，Gate 追溯以 handoff 为准。
6. **8 条基线测试失败**：未修，建议 M1 收尾前单独处置，避免掩盖新回归。

## 六、下一步（建议顺序）

1. **T68 补齐**（≈2.5 人日）：扩充到 20 组，接入模型抽取做端到端回放，补故障注入（中断续跑）。
2. **T69 + T71**（7 人日）：事实字段/关系表 schema、向量 BLOB 与格式元数据（迁移编号顺延），同时把「编辑后索引陈旧」做成显式标记。
3. **T73 + T74 定稿**（4 人日）：反馈三态与 salience；规格卡过 reviewer。
4. 之后进入 **M2**（事实抽取 v3 / 三级去重 / 整合 Worker）——这是让「长期印象」真正开始形成的关键。
