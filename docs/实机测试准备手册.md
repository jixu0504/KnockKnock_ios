## 二、你需要做的（一次性，约 10 分钟）

1. **连接 iPhone**：数据线连 Mac → 手机上点「信任此电脑」。
2. **打开开发者模式**（iOS 16+ 必需）：iPhone 设置 → 隐私与安全性 → 开发者模式 → 打开 → 重启手机。
3. **Xcode 登录 Apple ID**：Xcode → Settings → Accounts → `+` → Apple ID 登录。
   - 免费个人 Apple ID 即可（签名 7 天过期，过期重装）。
   - 想要 1 年签名：¥688/年 Apple Developer Program（计划书 §七.6 建议）。
4. **在 Xcode 里 Run 一次（生成证书）**：
   - 打开 `RhodesLink/iosApp/RhodesLink.xcodeproj`
   - Signing & Capabilities → Team 选你的个人 Team（Bundle Identifier 若冲突改一下，如 `com.yourname.rhodeslink`）
   - 选中你的 iPhone 作为运行目标 → Run。首次会自动注册设备、生成开发证书与描述文件。
5. **信任开发者证书**：iPhone 设置 → 通用 → VPN与设备管理 → 开发者 App → 信任。

完成后，后续每次构建安装只需一条命令：

```bash
./ios-port/scripts/build-device.sh
```

（脚本会自动检测设备/证书、构建 device 版、`devicectl` 安装；免费签名 7 天过期后重跑即可。）

## 三、真机当前能测什么 / 不能测什么

**能测（当前版本已具备）**
- 液态玻璃观感（iOS 26 真机效果，模拟器不具代表性）
- 键盘弹起/收起、输入框多行自适应、发送/停止
- 2,000 条消息时间线滚动帧率（真机 ProMotion/60Hz 重测）
- 深/浅色、动态字体、降低透明度/增强对比度/减弱动态效果
- `rhodes://` 深链、通知（授权时机）、剪贴板、文件导出
- 本地 SQLDelight 数据库、会话/角色/记忆真实数据读取
- 后台 BGTask 真实调度（模拟器不可用，必须真机验证）

**尚不能测（功能未接线）**
- ⚠️ **真实 AI 对话**：当前 AI 通道是确定性 fake（`DemoStreamingClient`，不联网）。
- 模型供应商配置 UI（11 家 + 自定义端点）、提示词编辑器、备份恢复 UI、群聊/动态/日记等页面。
