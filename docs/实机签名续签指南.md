# iOS 免费签名 7 天续签指南（不丢失 App 数据）

> 免费 Apple ID 签名的 App 描述文件只有 7 天有效期。到期后 App 打不开（提示"无法验证 App"）。
> **续签 = 用同一 Bundle ID 重新签名并覆盖安装**；iOS 会把它当作"升级"，**App 沙盒数据（聊天记录、设置、记忆等）全部保留**。

## 核心原则（防丢数据）

| 必须 | 说明 |
|---|---|
| ✅ **不要删除 App** | 在 iPhone 上长按删除 = 连数据一起删除，无法恢复 |
| ✅ **Bundle ID 保持不变** | 本工程为 `com.rhodeslink.app`；改了 Bundle ID 会被当成新 App（新数据容器） |
| ✅ **同一台 iPhone** | 免费账号的描述文件绑定已注册设备 |
| ✅ 覆盖安装（Xcode Run / devicectl install） | 同 Bundle ID 覆盖安装会保留 `Documents`、`Library`、Keychain 等数据 |

## 方法 A：Xcode 直接 Run（推荐，最简单）

1. iPhone 用数据线连接 Mac，解锁并「信任此电脑」
2. 打开工程：
   ```
   open ios/RhodesLink.xcodeproj
   ```
   （或 Xcode → File → Open → 选择 `ios/RhodesLink.xcodeproj`）
3. 顶部 Scheme 选择 **RhodesLink**，运行目标选择你的 **iPhone**（不是模拟器）
4. 左侧工程 → TARGETS → RhodesLink → **Signing & Capabilities**：
   - Team 选 `你的 Apple ID（Personal Team）`（当前工程为 `7PPJKDAPJZ`）
   - 勾选 **Automatically manage signing**
   - （若设备第一次用需要 `Register Device`，按提示操作）
5. 按 **⌘R（Run）**。Xcode 会：重新签名 → 覆盖安装到 iPhone → 启动 App
6. 若启动时提示未受信任：
   - iPhone → 设置 → 通用 → **VPN与设备管理** → 开发者 App → 点你的 Apple ID → **信任**
7. 完成。聊天/设置/记忆等数据都在（因为只是覆盖安装）。

> 若提示 "Provisioning profile doesn't support..."，在 Xcode → Settings → Accounts 打开一次账号面板刷新即可。

## 方法 B：命令行重新构建 + 覆盖安装（本项目脚本）

```bash
cd /path/to/workspace

# 1) 编译 KMP framework（真机 release）
cd shared
./gradlew :shared:linkReleaseFrameworkIosArm64
cd ..

# 2) xcodebuild 重新签名构建
xcodebuild build \
  -project ios/RhodesLink.xcodeproj \
  -scheme RhodesLink \
  -configuration Debug \
  -destination 'generic/platform=iOS' \
  -derivedDataPath /tmp/ios-build \
  -allowProvisioningUpdates \
  DEVELOPMENT_TEAM=7PPJKDAPJZ \
  CODE_SIGN_STYLE=Automatic

# 3) 覆盖安装（不会丢数据）
xcrun devicectl device install app \
  --device <你的 iPhone UDID> \
  /tmp/ios-build/Build/Products/Debug-iphoneos/RhodesLink.app
```

本项目也提供了一键脚本：`./scripts/build-device.sh`（自动检测设备 + 签名 + 安装）。

## 方法 C：用已导出的 IPA 重新签（仅在你没有工程源码时）

Xcode → **Devices and Simulators** → 选中 iPhone → 点 `+` → 选择 `.ipa` → 安装。
Xcode 会用当前账号重新签名后覆盖安装（同 Bundle ID 数据保留）。
或使用 Apple Configurator 2 / 第三方重签工具（如 iOS App Signer + AltStore/SideStore）。

## 数据安全网（建议做）

1. **App 内备份**：设置 → 数据与备份 → 导出完整备份（zip，含聊天/记忆/角色/设置），保存到"文件"App 或 AirDrop 到电脑
2. **iCloud/Finder 整机备份**：Finder → 你的 iPhone → 立即备份（恢复时同机恢复可还原 App 数据）
3. 续签前顺手做一次备份，万一操作失误可恢复

## 常见问题

**Q：续签后聊天记录会不会没？**
A：不会。覆盖安装（同 Bundle ID）时，iOS 保留 App 数据容器；只有"删除 App"才会清空。

**Q：到期后 App 还能打开吗？能导出数据吗？**
A：到期后无法启动，**但数据仍在设备里**——直接续签覆盖安装即可恢复使用；不要删除 App。

**Q：换了 Apple ID / Team 会怎样？**
A：只要 Bundle ID 与安装证书都有效，Xcode 会重新签名覆盖；数据保留。若 Bundle ID 变化则视为新 App。

**Q：Devicectl 安装报 "profile has not been trusted"？**
A：这是设备端信任问题，去 设置 → 通用 → VPN与设备管理 手动信任一次即可。
