> 前置：先升级安装 0.3.1（build 4），并且**升级前先导出一次完整备份**。

| 项 | 操作 | 通过标准 |

## 1. 测试剧本（建议用「11号」和一个新角色各跑一遍）

### 1.1 建立事实（会话 A，连续发）

1. `我叫阿澈，做游戏策划，住在杭州。`
2. `我喜欢喝美式咖啡，不加糖。`
3. `我养了一只布偶猫，叫团子，今年三岁。`
4. `我不喜欢吃香菜。`
5. `我答应你，周末一起去看电影。`

### 1.2 跨会话复述（新开会话 B）

6. `我还是喜欢喝美式咖啡，每天一杯。`
7. `团子最近学会了握手。`
8. `我讨厌下雨天。`

### 1.3 状态变化（新开会话 C）

9. `我最近搬到上海了。`
10. `我还是不喜欢吃香菜。`

### 1.4 查询（任意会话）

| # | 问法 | 期望 |
|---|---|---|
| Q1 | `我喜欢喝什么咖啡？` | 提到美式/不加糖；不应说“不知道” |
| Q2 | `团子几岁了？` | 三岁（查询含实体名「团子」，走实体通道） |
| Q3 | `我不吃什么？` | 香菜（否定事实） |
| Q4 | `我住在哪？` | 说上海；若同时提杭州，记为「状态变更未关闭旧事实」的已知问题 |
| Q5 | `我答应过你什么？` | 周末看电影（关系/承诺） |
| Q6 | `我讨厌什么天气？` | 下雨天 |

### 1.5 相反极性（新开会话 D）

11. `我现在不喜欢喝咖啡了。`
12. 问：`我喜欢喝咖啡吗？` → 期望只按“不喜欢”回答；不应同时说喜欢和不喜欢。

### 1.6 跨角色隔离

- 关闭“跨角色关系回忆”后，用另一个角色问：`你知道阿澈住在哪吗？` → 期望不引用阿澈的私聊内容。
- 再打开开关重复一次，记录是否有跨角色引用（用于对照）。

## 2. 功能检查点

| # | 检查点 | 操作 | 通过标准 |
|---|---|---|---|
| M1 | 记忆生成 | 聊完 1.1–1.3 后打开 功能 → 记忆管理 | 出现对应记忆（偏好/事实/否定），无大量重复条目 |
| M2 | 记忆维护 | 记忆管理 → 展开「记忆维护」 | 显示“一切正常”；点「检查记忆状态」后可刷新；「修复记忆」完成后仍正常 |
| M3 | 记忆详情 | 点开任意记忆 | 有内容、来源、时间；无 ID/库表名等技术字样 |
| M4 | 编辑 | 改一条偏好内容并保存 | 列表与详情同步；之后提问按新内容回答 |
| M5 | 删除传播 | 删除“团子三岁”相关记忆 | 再问团子年龄时不再引用该条；App 不崩 |
| M6 | 印象形成 | 多次提到同一偏好后，功能 → 大家的印象 | 出现按角色分组的印象；有证据数；可展开证据摘要 |
| M7 | 印象操作 | 对一条印象：拒绝 → 撤销拒绝；冻结 → 解冻；编辑 | 状态变化可见；拒绝后列表消失，撤销后回来；编辑后内容更新 |
| M8 | 分页 | 印象多于一页时下拉 | 能加载更多；不重复、不遗漏（同一条不出现两次） |
| M9 | 备份恢复 | 完整备份 → 清除/重装前先备份 → 恢复 | 恢复后记忆、印象、证据仍在；体检提示重建并最终恢复 |
| M10 | 冷启动 | 杀进程 → 重新打开 → 进入记忆管理 | 不闪退；维护状态正常；之前的记忆/印象仍在 |
| M11 | 跨角色开关 | 关/开各问一次 | 关闭时不串味；打开后行为变化可解释 |
| M12 | 长聊稳定性 | 连续聊 20–30 轮 | 回复正常；App 不卡死；记忆管理可打开 |

## 4. 已知限制（不要当作新 bug）

- **状态变更（Q4）**：`住在杭州` → `住在上海` 是不同事实键，当前版本不会自动关闭旧事实；T78 完整版才做 supersedes/双时间。请记录实际表现即可。
- **实体通道（Q2）**：只有查询里出现完整实体名（如「团子」）时才生效；问「我的猫几岁」可能召回不到。
- **印象形成**：需要 L2/L3 先形成（同一事实多次、跨会话）；只聊一两轮看不到印象是正常的。
- **冲突确认**：冲突会标记 `suspected`，但当前没有确认/取代 UI；不会自动关闭旧事实。
- **抽取合规率**：依赖模型输出；结构化字段缺失时只影响 L2/L3/印象形成，不影响已存记忆。
- **8 条基线网络测试失败**：与本次记忆功能无关（本地测试服务依赖）。
- **Android**：兼容 DDL 已补，未实编；本测试只针对 iOS。
