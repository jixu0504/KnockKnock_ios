### 每份人设文档的结构

1. **标题与档案引言** —— 取自游戏内「代理人档案」的原句
2. **信息表** —— 全名/英文名/稀有度/属性/特性/阵营/种族/生日/版本/头像
3. **一、官方档案** —— 档案文案 + 他人评价（原文引用，一字未改）
4. **二、人设解读** —— 性格内核 / 行为与语言习惯 / 背景与处境
5. **三、人际关系** —— 关系表，每行注明依据（引自原文或阵营设定）
6. **四、联系人适配** —— 备注名、头像、个性签名、分组、对你的称呼、2 条开场白、2 条典型回复、口头禅、雷区

### 质量保证

- **原文零改写**：引言、档案文案、他人评价全部由脚本与原始 wikitext 逐字比对，63/63 通过
- **关系不臆造**：关系表只收「他人评价说话人」「正文提及」「同阵营」三类有据可查的关系
- **结构一致**：63 篇六段结构与 9 项联系人字段自动校验，0 处缺失；无「综上所述」类作文腔
- **文风统一**：以 `057_安比.md` 为样板，全篇采用游戏内档案员的克制观察口吻

## 三、数据来源

- **文本**：B 站绝区零 Wiki 角色页（`wiki.biligame.com/zzz`）的「官方介绍 / 详细情报 / 合作备注」三段
- **世界观**：同站「世界观」词条 + 63 份档案原文中的人物与机构描述
- **头像**：Wiki 的 `角色头像-<角色名>.png`（米哈游官方素材）
- **完整性**：62 位代理人与独立数据源 dotgg 交叉核对一致；主角铃（非代理人，不在 Wiki 代理人名录中）单独补抓；赛维里安、菲欧妮（3.3 新角色）Wiki 暂无方形头像，已用官方立绘裁切补位

## 四、脚本

| 脚本 | 作用 |
| --- | --- |
| `fetch.py` | 抓取角色名单与头像 → `characters.json` + `avatars/` |
| `build.py` | 规范化头像，导出 CSV / HTML 图鉴 / 总览图 |
| `parse_profiles.py` | 解析 wiki 原文 → `profiles.json` |
| `build_relations.py` | 抽取人际关系 → `profiles_enriched.json` |
| `build_index.py` | 从人设文档提取联系人字段 → 总表 CSV + 卡片页 + 索引 |
| `verify_docs.py` | 校验文档结构、原文引用、字段完整性 |

重跑顺序：`fetch.py → build.py → parse_profiles.py → build_relations.py →（撰写文档）→ build_index.py → verify_docs.py`

> 说明：铃是玩家扮演的绳匠「法厄同」之一，不在代理人名录中，Wiki 也没有她的「代理人档案」。她的资料取自角色页信息框与官方介绍，人设解读则依据她在 57 位代理人「合作备注」中的留言（语料见 `raw/铃的留言语料.md`）。
