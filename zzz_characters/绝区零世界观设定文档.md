## 〇、一句话总览

在一场把旧文明连同旧都一起吞掉的灾难之后，人类只剩下最后一座巨型都市**新艾利都**。城市靠着一种只在灾难残骸里才有的资源**以太**活着，而提取以太必须钻进**空洞**——一个无视物理规则、会吞人、会增殖的异空间。于是这座城里长出了一整套新职业：给盗洞客带路的**绳匠**、靠委托吃饭的**代理人**、管着空洞的**协会**和**军方**，以及数不清的、在街头和财阀之间讨生活的**阵营**。

故事的主角**法厄同**（哲与铃兄妹，经营着一家录像店），就是这座城市里最传奇的绳匠。

## 一、世界坐标：新艾利都

### 1.1 灾难与旧都※

新艾利都之前，有过一座「旧都」。旧都在某次空洞灾害中陷落，史称**旧都陷落**。这场灾难是整整一代人的伤口：有人失去了父母（叶瞬光），有人失去了身体（奥波勒斯小队的「鬼火」在旧都陷落中重伤，意识被转入武器），也有人在废墟里捡到了来路不明的少女（安比）。

新艾利都是在旧都废墟之上重建的、也是目前已知**唯一**能与空洞长期共存的大型都市。

### 1.2 城市结构

| 区域 | 说明 |
| --- | --- |
| **丽都区** | 城市的核心地带，资本、媒体与偶像工业的所在地。耀嘉音被称为「丽都第一歌姬」，一句话就能点出这里的调性：资本只手撑天，名流与舆论共生。 |
| **六分街** | 平民街区，也是法厄同的录像店所在。安比、比利这些人的日常都发生在这里。街面不大，人情很近，消息流通得比绳网还快。 |
| **外环** | 城市边缘地带，摩托帮、雇佣兵、清道夫的地盘。这里的规矩不写在法条里，写在拳头和车队排位里——卡吕冬之子、坎卜斯黑枝的活动半径都在这一带。 |
| **雅努斯区** | 治安局的重要辖区，都市秩序部与刑侦特勤组的驻在地。 |
| **热望角** | 娱乐与休闲去处，年轻人翘班逃跑的目的地。 |
| **罗斯凯利法** | 拥有世家、局署与工坊的传统势力圈，讲究血统、名声与公务体系（空域巡戍局、外务筹策局、弗林特工坊皆出于此）。 |

### 1.3 社会形态

这是一座**高度公司化**的城市：治安局管地面，防卫军管大灾，协会管资格，财阀管钱袋子。街头与体制之间有一层巨大的灰色地带，靠委托、人情和绳网的信息差运转。绝大多数代理人都活在这层灰色地带里。

## 二、空洞：这个世界的物理规则

### 2.1 空洞的定义※

**空洞**是一种在空间中凭空出现、并按一定速率持续膨胀的不可视空间领域。它的特征是不讲道理的五条：

1. 边界无视一切已知物质的阻隔——墙挡不住它；
2. 可以进入，**但无法正常脱离**；
3. 任何已知手段都无法从外部观测内部；
4. 放任不管就会持续活性扩张，并异化其内部的一切；
5. 消灭空洞内的敌人，可以降低或抑制它的活性。

### 2.2 以太※

**以太**是仅在空洞中产生的神秘资源。被空洞扭曲的地质环境会催生出极端条件下才可能稳定的物质，以太是其中最宝贵的一种。

- 只在空洞中产生；
- 是旧文明能源体系**唯一可行的替代品**，万能泛用；
- 可转化为各种形态，空洞内常见为固态晶体；
- 真正「开采」以太的最好办法，是**击杀空洞内的敌人**；
- 开采风险极高。

这座城市的经济、技术、甚至政治，全部建立在这句话上：**人必须进空洞，才能活下去。**

### 2.3 侵蚀与以骸※

| 概念 | 说明 |
| --- | --- |
| **侵蚀效应** | 事物从最小构成单位开始被以太侵染、替代、扭曲，最终彻底改变性质。只要身处含以太的环境，侵蚀就在发生。 |
| **以骸（Ethereal）** | 以太高度活性化后诞生的异常「生命体」，对非以骸、非侵蚀体的生命抱有明确敌意，只能在空洞内存活。是空洞最标志性的危险，也是以太资源的主要产出端。 |
| **侵蚀体** | 迷失空洞太久、被烈性以太侵蚀而异化的人或物。已丧失神智，开始攻击同类。 |
| **以太适性** | 个体对以太侵蚀的耐受能力。适性高的人能在空洞里待更久、甚至从以太中获得增强。这是选人入行的硬门槛。 |

### 2.4 特殊空洞※

- **零号空洞**：英文代号 Hollow Zero，另有中文名「灵薄」。新艾利都登记在案并由官方管控的大型空洞之一，据称与旧都陷落直接相关。
- **伴生空洞**：一个规模足够大的空洞所诱发、扩张出的新空洞。可以通过清剿其中的活体以太或侵蚀体来抑制它，使其收缩甚至消失。

## 三、职业生态：谁在靠空洞吃饭

### 3.1 绳匠※

在人类不得不接触空洞的时代，**为进入空洞的人提供非官方渠道援助**的从业者，就是绳匠。

绳匠不一定要亲自下场，他们的核心资产是**信息**：哪条路能走、哪个区域活性低、什么时候必须撤离。一个顶级绳匠的价码，往往比整支队伍都贵。

已知绳匠：乔伊斯、伊德海莉、**法厄同（哲 / 铃，主角兄妹）**。

> 对「联系人替换」的意义：**绳匠**是对主角最自然的统称。绝大多数代理人会用「绳匠」「法厄同」来称呼你。

### 3.2 盗洞客※

没有空洞调查协会许可、却主动进入空洞的人。因为拿不到协会的返程许可与资源，他们**必须**依靠绳匠。这是绳匠与盗洞客之间天然的共生关系。

### 3.3 空洞调查协会（HIA）※

由做空洞营生的人群自发成立的互助协作组织，从「空洞调查互助会」演变而来。职责包括：吸纳培训与管理调查员、发布和接受官方委托、记录灾情数据、核发报酬与「萝卜」。同时，它也是空洞调查员公众形象的主要维护者——每年砸大笔经费做宣传，保证一直有人愿意跳进这个行业。

### 3.4 绳网※

全称「绳结网络」（Inter-Knot）。绳匠与盗洞客的论坛，鱼龙混杂的情报交易场。委托、资讯、悬赏都在这里流通，连空洞调查协会不便出面处理的事也会外包到这里。

> 对「联系人替换」的意义：绳网是这个世界里天然的「社交软件」隐喻。把联系人放进「绳网」分组、用「发个帖子」「接个委托」来解释聊天场景，是最顺的世界观接法。

### 3.5 萝卜与罗塞塔数据※

- **萝卜**：基于大量空洞观测数据生成的「逃生路径」，本质是一份有时效的空洞地图。智能设备或邦布都能读取，数据有效期内可以靠它安全离开空洞。
- **罗塞塔数据**：新艾利都所有「萝卜」数据的母本。

## 四、技术与日常

| 名词 | 说明 |
| --- | --- |
| **邦布**※ | 原为协助人们应对空洞事务的辅佐式小型智能机械，如今已泛化成个人智能设备，生活的方方面面都有它的身影。 |
| **驱动盘**※ | 掺入以太物质制成的特殊音频储存媒介，配合调制解调设备可释放特殊声波，扰乱、减缓空洞内的以太侵蚀；以太适性良好的人还能从中获得增强。 |
| **音擎** | 与驱动盘搭配使用的装备，代理人的主要武装载体。 |
| **丁尼**※ | 这座城市的货币。 |
| **录像店（Random Play）**※ | 法厄同兄妹经营的店面，也是狡兔屋、代理人圈子日常聚集的情报中转站。有人甚至在竞选这里二楼的室友。 |

## 六、给「联系人替换」的世界观接法

### 6.1 称呼体系

- **绳匠 / 法厄同**：最通用、最职业化，适合大多数代理人。
- **店长**：狡兔屋、怪啖屋、以及常来录像店的人会用。
- **长官 / 组长 / 课长**：体制内角色在正式场合的自称与他称。
- **老大 / 老板**：外环与街头角色，带着江湖气。

### 6.2 六类社交圈（建议的通讯录分组）

| 分组 | 成员特征 | 聊天氛围 |
| --- | --- | --- |
| 狡兔屋 & 六分街 | 万事屋、街头熟人 | 吐槽、催委托、借钱不还 |
| 治安局 & 防卫军 | 体制内、纪律感强 | 公文口吻、任务简报、偶尔破功 |
| 外环 · 卡吕冬 | 机车、拳台、义气 | 直球、脏话边缘、赢就是一切 |
| 财阀 & 局署 | 世家、财团、审查 | 客套、试探、字字带钩 |
| 偶像 & 演艺 | 舞台、粉丝、资本 | 元气、营业、后台的疲惫 |
| 怪啖屋 & 绳网 | 匿名、故事、情报 | 网名、梗、都市传说 |

### 6.3 日常语汇替换表

| 现实词 | 世界观替换 |
| --- | --- |
| 微信 / 私信 | 绳网私信、终端联络 |

| 红包 / 转账 | 丁尼 |

| 新闻 | 丽都播报、绳网热帖 |

### 6.4 三条世界观红线

1. **空洞不可随意出入**。任何"出门散步"式的描写，都必须有萝卜、绳匠或官方许可作为前提，否则人物会当场失格。
2. **以太不是魔法**。它的价值来自危险和稀缺，任何把以太写成"随便用的能量"的表述都会脱离设定。
3. **阵营立场不可混同**。财阀、军方、街头、怪盗之间互相提防是常态，让不同阵营的人毫无芥蒂地称兄道弟，会立刻露馅。
